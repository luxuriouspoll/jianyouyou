# 简历优化原则

面向**任意目标岗位**（运维、开发、测试、数据、产品、云原生等）的已有简历。目标是在**事实不变**的前提下，让表达更专业、结构更清晰、成果量化、岗位匹配。

## 使用方法

- 遵循本技能时，请以 **[references/principles.md](references/principles.md)** 为**详细版唯一事实来源**，按其版块原则逐条执行。
- `principles.md` 包含完整细则：真实性边界、排版、专业技能、个人优势、工作 / 项目经历、教育背景、内容难易与粒度、岗位与年限侧重、量化模板、篇幅约束、评分锚点、输出自检等。

## 核心约束（最高优先）

- 只能改写、重组、强化用户**已确认**的真实经历。
- 严禁新增或篡改姓名、公司、项目、职责、技能、证书、日期、量化数字等事实。
- 缺失信息必须提示补充或保留为待完善项，绝不自行推断成事实。

> 详见 [references/principles.md](references/principles.md)。
